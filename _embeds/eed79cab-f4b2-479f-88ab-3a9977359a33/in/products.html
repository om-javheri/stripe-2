Frequently asked questions

Learn more about Stripe's products.

What is Stripe?

Stripe is a programmable financial infrastructure that helps you build and run a global business. You can use Stripe to accept payments, manage revenue, prevent fraud, move money across borders and access a suite of developer tools and APIs. Stripe processes trillions of dollars annually for companies ranging from early-stage startups to large enterprises.

What does Stripe do?

Stripe helps businesses of all kinds accept payments globally, prevent fraud, automate revenue management, move and manage money, monetise payments and financial services and operate across borders.

What types of businesses use Stripe?

Businesses of every size and model use Stripe—from early-stage startups to global enterprises, across retail, travel, AI, insurance, SaaS, nonprofits, online marketplaces, and more.

How does Stripe support AI businesses and agentic commerce?

Stripe is the economic infrastructure for AI. Whether you're monetising an AI product, making your catalogue discoverable to AI agents or building agents that can transact on your behalf, Stripe can support it – from flexible billing models to agentic checkout and developer tools built specifically for how agents work.

How much does Stripe cost?

Stripe's pricing depends on which payment methods and products you use. For card payments, you pay a per-transaction rate that varies by card type, country and any additional features you enable.

Where can developers learn more about Stripe API and technical documentation?

Stripe's documentation covers everything from API references and SDK guides to quickstarts and code samples. Developers can explore interactive tutorials, test integrations in a sandbox environment and manage live implementations – all from docs.stripe.com.
